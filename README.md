# AnurasetEurope
This repository hosts the custom code used to compile, curate, and validate the AnurasetEurope metadata manifest. 
AnurasetEurope is a curated, fully harmonized bioacoustic metadata index of 8.684 anuran vocalization recordings spanning 37 species across the European continent. It provides a community resource for research on European anuran bioacoustics and automated acoustic analysis.

The dataset including the audio files can be found at the accompanying Zenodo release: https://zenodo.org/records/21282595.
